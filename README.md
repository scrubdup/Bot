# Both Sides Growth Bot

Mobile-first dashboard for the Both Sides of the Dollar audience-growth and digital-book sales workflow.

## Goals
- Rank money/investing audience targets.
- Separate growth targets from likely book-buyer targets.
- Generate natural, niche-specific engagement suggestions.
- Match prospects to the most relevant book.
- Track targets worked, followers and book sales.
- Keep outbound Instagram engagement human-approved rather than automated spam.

## Setup
Open Settings in the app and add the Instagram username, daily target and checkout link for each book.

## Deploy
This repository is a static site. Import the repository into Vercel and deploy with no build command required.
